# Laboratorio 2 – Mi pedido de cafetería

**Curso:** Programación de Dispositivos Móviles  
**Tecnología:** Flutter y Dart

## Descripción

Aplicación para seleccionar productos de una cafetería, modificar sus cantidades y consultar el total del pedido.

## Productos

- Café: Q10.00
- Sándwich: Q25.00
- Jugo: Q12.00
